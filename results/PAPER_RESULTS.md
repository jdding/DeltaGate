## E2E 控制变量实验 (2026-04-12)

**问题**: DeltaGate 的价值来自"gating 机制"还是"E2E 训练范式"？

### 完整对比

| Model | short | 30-90d | 90-180d | 180-365d | >365d |
|-------|-------|--------|---------|---------|-------|
| SASRec baseline | 0.1998 | 0.1099 | 0.0980 | 0.0778 | 0.0297 |
| DG-SASRec (checkpoint) | 0.2166 | 0.1173 | 0.1099 | 0.0995 | 0.0573 |
| **TimeConcat E2E** | **0.2334** | **0.1215** | **0.1152** | **0.1087** | **0.0797** |
| **DeltaGate E2E** | 0.2092 | 0.1169 | 0.1094 | 0.0998 | 0.0571 |

### 关键发现

### 三大硬核分析：TimeConcat E2E vs DG-SASRec Plugin

| 分析维度 | TimeConcat E2E | DG-SASRec Plugin | 胜者 |
|---------|----------------|------------------|------|
| **>365d 性能** | **0.0797** | 0.0573 | TimeConcat E2E (+39%) |
| **参数效率** (Eff@365d per 1M) | 0.0189 | **0.8676** | DG-SASRec Plugin (46x) |
| **short 活跃用户** | **0.2334** (+16.8%) | 0.2166 (+8.4%) | TimeConcat E2E |
| **Backbone 漂移** | 122.8% | ~0% (frozen) | DG-SASRec Plugin |
| **Gate 机制** | 无 (additive concat) | **选择性维度过滤** | DG-SASRec Plugin |

### 核心结论

1. **TimeConcat E2E 绝对性能更强**（>365d: 0.0797 vs 0.0573，领先 39%），但需训练全部 2.6M 参数且 backbone 漂移 122.8%

2. **DG-SASRec Plugin 参数效率 46 倍**：用 1/40 参数量达到 72% 的 >365d 性能，且完全保留 backbone

3. **E2E 模式下 gating 无意义**：backbone 自适应导致 Δt 信号冗余，gate 完全饱和（g>0.8 恒定）

4. **Plugin 模式下 gating 有意义**：冻结 backbone 迫使 gate 成为唯一时间处理机制，体现"维度过滤"的生物学合理性——"神经通路不被重新布线，而是被门控"
